# Analíticas — Congresos de Historia de la Fotografía

Sitio estático de consulta de 107 registros analíticos.

- 1.º Congreso (1992): 28 trabajos
- 2.º Congreso (1993): 38 trabajos
- 3.º Congreso (1994): 41 trabajos

La interfaz está en `index.html` y los registros se cargan desde `data1.js` a `data5.js`.

## Publicación con GitHub Pages

En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**, elegir `main` y `/ (root)`, y guardar.
